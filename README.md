# Year 9 Enterprise Information Systems Website

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `9CT_Assessment_Task_3.pdf` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the published website address.

## Notes

- Student responses and lesson completion are saved in the browser using `localStorage`.
- Progress does not automatically transfer between browsers or devices.
- The page is fully standalone and uses no external libraries.
- The assessment PDF link expects the PDF to remain in the same folder as `index.html`.
